A recipe is the single source of truth for how a pizza is made. It encodes every production parameter — dough weight, sauce type, toppings, oven temperature, and bake duration — into a reusable blueprint that you attach to a production run. When you start a run, the platform reads the recipe and uses its values to drive each machine in the assigned production line. Keeping your recipes accurate and well-named is key to consistent output across your factory.

## Recipe fields

| Field | Type | Description |
|---|---|---|
| `id` | string | Unique identifier for the recipe, e.g. `rec_01hx4mn` |
| `name` | string | Human-readable display name for the recipe |
| `version` | integer | Auto-incremented version number, starting at `1` |
| `dough_weight_g` | integer | Target dough weight per pizza base, in grams |
| `sauce` | string | Sauce type applied to the base, e.g. `tomato`, `white`, `pesto` |
| `toppings` | array of strings | Ordered list of toppings applied at the topping station |
| `bake_temp_celsius` | integer | Target oven temperature in degrees Celsius |
| `bake_duration_seconds` | integer | Time the pizza spends in the oven, in seconds |
| `created_at` | string | ISO 8601 timestamp of when the recipe was first created |
| `updated_at` | string | ISO 8601 timestamp of when the recipe was last modified |

## Example recipe object

```json
{
  "id": "rec_01hx4mn",
  "name": "Margherita 12in Classic",
  "version": 3,
  "dough_weight_g": 280,
  "sauce": "tomato",
  "toppings": [
    "mozzarella",
    "fresh_basil",
    "olive_oil"
  ],
  "bake_temp_celsius": 285,
  "bake_duration_seconds": 420,
  "created_at": "2024-09-03T14:22:00Z",
  "updated_at": "2024-11-20T09:05:00Z"
}
```

## Recipe versioning

Recipes are versioned automatically. Every time you update a recipe — changing the bake temperature, swapping a topping, or adjusting dough weight — Pizzeria Co increments the `version` number and records the change. Existing and in-progress production runs are always pinned to the version they were started with, so an update never disrupts an active run.

<Note>
  When you retrieve a production run, it includes a `recipe_version` field that tells you exactly which version of the recipe was used. This gives you a reliable audit trail for quality control and lets you trace any batch back to its exact specifications.
</Note>

<Tip>
  Adopt a consistent naming convention that encodes size and variant directly in the recipe name — for example, `Margherita 12in Classic` or `Pepperoni 9in Thin`. Clear names make it much easier to select the right recipe when creating production runs through the API or any dashboard integration you build on top of it.
</Tip>

## API endpoints

Use the following endpoints to manage your recipes. All recipe endpoints require authentication.

### List all recipes

Retrieve a paginated list of all recipes in your workspace.

```bash
GET https://api.pizzeriaco.com/v1/recipes
```

**Example response**

```json
{
  "data": [
    {
      "id": "rec_01hx4mn",
      "name": "Margherita 12in Classic",
      "version": 3,
      "dough_weight_g": 280,
      "sauce": "tomato",
      "toppings": ["mozzarella", "fresh_basil", "olive_oil"],
      "bake_temp_celsius": 285,
      "bake_duration_seconds": 420,
      "created_at": "2024-09-03T14:22:00Z",
      "updated_at": "2024-11-20T09:05:00Z"
    }
  ],
  "pagination": {
    "page": 1,
    "per_page": 20,
    "total": 1
  }
}
```

### Create a recipe

Create a new recipe. The `version` starts at `1` automatically.

```bash
POST https://api.pizzeriaco.com/v1/recipes
```

**Example request body**

```json
{
  "name": "Pepperoni 9in Thin",
  "dough_weight_g": 200,
  "sauce": "tomato",
  "toppings": ["mozzarella", "pepperoni"],
  "bake_temp_celsius": 300,
  "bake_duration_seconds": 360
}
```

**Example response**

```json
{
  "id": "rec_01hx7ab",
  "name": "Pepperoni 9in Thin",
  "version": 1,
  "dough_weight_g": 200,
  "sauce": "tomato",
  "toppings": ["mozzarella", "pepperoni"],
  "bake_temp_celsius": 300,
  "bake_duration_seconds": 360,
  "created_at": "2024-12-02T10:00:00Z",
  "updated_at": "2024-12-02T10:00:00Z"
}
```

### Update a recipe

Update one or more fields on an existing recipe. Each successful update increments `version` by one.

```bash
PUT https://api.pizzeriaco.com/v1/recipes/{recipe_id}
```

**Example request body**

```json
{
  "bake_temp_celsius": 310,
  "bake_duration_seconds": 340
}
```

### Delete a recipe

Permanently delete a recipe. You cannot delete a recipe that is currently attached to an active production run.

```bash
DELETE https://api.pizzeriaco.com/v1/recipes/{recipe_id}
```

For full request and response schemas, see the [Recipes API reference](/api-reference/recipes/list).
