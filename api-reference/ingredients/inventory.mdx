title: "GET /ingredients/inventory — Check Inventory Levels"

---

Use this endpoint to check the current stock levels across all ingredients in your facility. Each record tells you how much of an ingredient is on hand, whether it has fallen below your configured low-stock threshold, and when it was last restocked. This is the recommended pre-flight check before starting a large production run.

## Endpoint

```
GET /ingredients/inventory
```

## Query Parameters

<ParamField query="low_stock_only" type="boolean">
  Set to `true` to return only ingredients where `is_low_stock` is `true`. Useful for building restock alerts or pre-run inventory checks.
</ParamField>

<ParamField query="category" type="string">
  Filter results to a specific ingredient category. One of: `dough`, `sauce`, `topping`, or `packaging`.
</ParamField>

## Response

<ResponseField name="inventory" type="array of objects">
  The list of inventory records matching your query.

  <Expandable title="Inventory item fields">
    <ResponseField name="ingredient_id" type="string">
      The ID of the ingredient this record belongs to (e.g. `ing_01hx6ru`).
    </ResponseField>

    <ResponseField name="name" type="string">
      The name of the ingredient.
    </ResponseField>

    <ResponseField name="unit" type="string">
      The unit of measurement for this ingredient (e.g. `kg`, `liters`).
    </ResponseField>

    <ResponseField name="quantity_available" type="number">
      The current stock level, expressed in the ingredient's unit.
    </ResponseField>

    <ResponseField name="low_stock_threshold" type="number">
      The threshold below which the ingredient is considered low stock. Configure thresholds in your account settings.
    </ResponseField>

    <ResponseField name="is_low_stock" type="boolean">
      `true` if `quantity_available` is below `low_stock_threshold`. Use this flag to trigger restock workflows.
    </ResponseField>

    <ResponseField name="last_restocked_at" type="string">
      ISO 8601 timestamp of the most recent restock event for this ingredient.
    </ResponseField>
  </Expandable>
</ResponseField>

## Important Notes

<Warning>
  Inventory levels are updated asynchronously after a production run completes. Allow a few seconds after a run's status changes to `completed` before querying inventory if you need to reflect the consumed quantities.
</Warning>

## Code Example

Fetch only low-stock ingredients to build a restock alert:

```bash
curl 'https://api.pizzeriaco.com/v1/ingredients/inventory?low_stock_only=true' \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response

```json
{
  "inventory": [
    {
      "ingredient_id": "ing_01hx6ru",
      "name": "mozzarella",
      "unit": "kg",
      "quantity_available": 42.0,
      "low_stock_threshold": 50,
      "is_low_stock": true,
      "last_restocked_at": "2024-03-12T06:00:00Z"
    }
  ]
}
```

## Fetching Full Inventory

To retrieve stock levels for all ingredients regardless of status, omit the `low_stock_only` parameter:

```bash
curl https://api.pizzeriaco.com/v1/ingredients/inventory \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Filtering by Category

To check stock levels for dough ingredients only:

```bash
curl 'https://api.pizzeriaco.com/v1/ingredients/inventory?category=dough' \
  -H "Authorization: Bearer YOUR_API_KEY"
```
