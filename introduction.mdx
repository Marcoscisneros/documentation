Welcome to Pizzeria Co's developer documentation. Whether you're building an automated production scheduler, integrating ingredient inventory into your ERP system, or monitoring your factory floor in real time, the Pizzeria Co REST API gives you programmatic control over every stage of your pizza manufacturing workflow. This documentation covers everything you need to get up and running quickly — from authenticating your first request to orchestrating large-scale production runs.

## What you can do

The Pizzeria Co API gives you complete programmatic access to your factory's production infrastructure. Here are the key capabilities at your fingertips:

<CardGroup cols={2}>
  <Card title="Control Factory Machinery" icon="industry" href="/concepts/machines">
    Send commands to individual machines, check their status, and respond to state changes in real time — all over a simple REST interface.
  </Card>
  <Card title="Manage Recipes" icon="pizza-slice" href="/concepts/recipes">
    Create, update, and delete pizza recipes with full control over dough weight, sauce type, toppings, bake temperature, and duration.
  </Card>
  <Card title="Orchestrate Production Runs" icon="play" href="/concepts/production-runs">
    Start, monitor, and cancel production jobs. Assign specific machines to each run and track output quantities as they complete.
  </Card>
  <Card title="Monitor Machine Status" icon="chart-line" href="/guides/monitor-machines">
    Poll real-time status updates from every machine on your production line — including idle, running, maintenance, and error states.
  </Card>
  <Card title="Track Ingredient Inventory" icon="boxes-stacked" href="/concepts/ingredients">
    Query current stock levels for every ingredient, set low-stock thresholds, and integrate reorder alerts into your existing supply chain tools.
  </Card>
  <Card title="Secure API Key Auth" icon="shield-halved" href="/authentication">
    All API requests are authenticated with long-lived API keys you generate from your dashboard — no OAuth flows or token refreshes required.
  </Card>
</CardGroup>
