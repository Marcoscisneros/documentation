Use this endpoint to retrieve the full details of a single production run — including its current status, how many pizzas have been completed, and any error information. This is the primary way to track the progress of an active run from your application.

## Endpoint

```
GET /production/runs/{id}
```

## Path Parameters

<ParamField path="id" type="string" required>
  The ID of the production run to retrieve (e.g. `run_01hx5qp`). Run IDs are returned when you [start a run](/api-reference/production/start-run).
</ParamField>

## Response

<ResponseField name="id" type="string">
  The unique ID of this production run.
</ResponseField>

<ResponseField name="recipe_id" type="string">
  The ID of the recipe used for this run.
</ResponseField>

<ResponseField name="recipe_version" type="integer">
  The snapshot version of the recipe that was captured when the run started.
</ResponseField>

<ResponseField name="quantity" type="integer">
  The total number of pizzas requested for this run.
</ResponseField>

<ResponseField name="quantity_completed" type="integer">
  The number of pizzas produced so far. Divide this by `quantity` to calculate the percentage complete.
</ResponseField>

<ResponseField name="machine_ids" type="array of strings">
  The IDs of the machines assigned to this run.
</ResponseField>

<ResponseField name="status" type="string">
  The current state of the run. One of: `queued`, `running`, `paused`, `completed`, `failed`, or `cancelled`.
</ResponseField>

<ResponseField name="started_at" type="string">
  ISO 8601 timestamp of when the run was created and queued.
</ResponseField>

<ResponseField name="completed_at" type="string">
  ISO 8601 timestamp of when the run finished. `null` if the run has not yet completed.
</ResponseField>

<ResponseField name="error" type="string">
  A description of the error if the run entered a `failed` state. `null` if no error has occurred.
</ResponseField>

## Tracking Progress

To track an active run, poll this endpoint every **5–10 seconds**. Calculate completion percentage with:

```
progress = quantity_completed / quantity * 100
```

<Tip>
  The run is finished when `status` is `completed`, `failed`, or `cancelled`. Once the run reaches a terminal state, stop polling and check `quantity_completed` for the final count.
</Tip>

## Code Example

```bash
curl https://api.pizzeriaco.com/v1/production/runs/run_01hx5qp \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Response (in progress)

```json
{
  "id": "run_01hx5qp",
  "recipe_id": "rec_01hx4mn",
  "recipe_version": 1,
  "quantity": 500,
  "quantity_completed": 237,
  "machine_ids": ["mch_01hx3k9", "mch_01hx3ka"],
  "status": "running",
  "started_at": "2024-03-15T10:00:00Z",
  "completed_at": null,
  "error": null
}
```

## Errors

| Status | Description |
|--------|-------------|
| `404` | No run with the provided `id` exists in your account. |
