title: "GET /recipes — List All Pizza Recipes"
sidebarTitle: "List Recipes"

---

Use this endpoint to retrieve all pizza recipes stored in your account. The response is paginated and each recipe object includes the full set of production parameters — dough weight, sauce, toppings, oven temperature, and bake duration — so you can review or select recipes without making additional requests.

## Endpoint

```
GET https://api.pizzeriaco.com/v1/recipes
```

## Query Parameters

<ParamField query="limit" type="integer" default={20}>
  Number of recipes to return per page. Maximum value is `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from a previous response's `next_cursor` field. Omit to start from the beginning of the list.
</ParamField>

## Response Fields

<ResponseField name="recipes" type="array">
  An array of recipe objects.

  <Expandable title="Recipe object fields">
    <ResponseField name="id" type="string">
      Unique identifier for the recipe (e.g. `rec_01hx4mn`).
    </ResponseField>

    <ResponseField name="name" type="string">
      Human-readable name for the recipe.
    </ResponseField>

    <ResponseField name="dough_weight_g" type="integer">
      Dough weight in grams.
    </ResponseField>

    <ResponseField name="sauce" type="string">
      Sauce type used in the recipe: `tomato`, `white`, `pesto`, or `bbq`.
    </ResponseField>

    <ResponseField name="toppings" type="array of strings">
      List of topping ingredients included in the recipe.
    </ResponseField>

    <ResponseField name="bake_temp_celsius" type="integer">
      Oven temperature in degrees Celsius.
    </ResponseField>

    <ResponseField name="bake_duration_seconds" type="integer">
      Total bake time in seconds.
    </ResponseField>

    <ResponseField name="version" type="integer">
      Current version number of the recipe. Increments with each update.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the recipe was created.
    </ResponseField>

    <ResponseField name="updated_at" type="string">
      ISO 8601 timestamp of the most recent update to the recipe.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Cursor to pass as the `cursor` query parameter to retrieve the next page. Returns `null` when you have reached the last page.
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of recipes across all pages.
</ResponseField>

## Example Request

```bash
curl https://api.pizzeriaco.com/v1/recipes \
  -H "Authorization: Bearer YOUR_API_KEY"
```
