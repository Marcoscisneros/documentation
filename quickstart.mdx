---

This guide walks you through the essential steps to start using the Pizzeria Co API: authenticating your requests, discovering the machines on your production line, defining a pizza recipe, and kicking off your first production run. All you need is an API key and a terminal — let's get started.

<Steps>
  <Step title="Get your API key">
    Every request to the Pizzeria Co API must include a valid API key. Head to [https://dashboard.pizzeriaco.com](https://dashboard.pizzeriaco.com), navigate to **Settings → API Keys**, and create a new key. Give it a descriptive name (for example, `my-first-integration`) and copy it immediately — the full key is only shown once.

    <Note>
      Store your API key in an environment variable or a secrets manager right away. Never paste it directly into your code or commit it to source control. See the [Authentication guide](/authentication) for best practices.
    </Note>

    For the rest of this guide, replace `YOUR_API_KEY` in every example with the key you just copied.
  </Step>

  <Step title="List your machines">
    Before you can run a production job, find out which machines are available on your factory line. Send a `GET` request to the `/machines` endpoint:

    ```bash title="List all machines"
    curl https://api.pizzeriaco.com/v1/machines \
      -H "Authorization: Bearer YOUR_API_KEY"
    ```

    A successful response returns an array of machine objects, each with a unique ID, human-readable name, type, current status, and capacity:

    ```json title="Response"
    {
      "machines": [
        {
          "id": "mch_01hx3k9",
          "name": "Dough Mixer Pro 3000",
          "type": "dough_mixer",
          "status": "idle",
          "capacity_kg": 50
        },
        {
          "id": "mch_01hx3ka",
          "name": "Conveyor Oven Line A",
          "type": "oven",
          "status": "idle",
          "capacity_kg": 200
        }
      ]
    }
    ```

    Note the `id` values for any machines with `"status": "idle"` — you'll need them in Step 4 when you start your production run.

    <Tip>
      A machine in `"idle"` status is ready to accept work. Machines in `"running"`, `"maintenance"`, or `"error"` states cannot be assigned to new production runs until they return to `"idle"`.
    </Tip>
  </Step>

  <Step title="Create a recipe">
    A recipe defines everything the machinery needs to produce a pizza: dough weight, sauce, toppings, bake temperature, and duration. Create a recipe by sending a `POST` request to `/recipes`:

    ```bash title="Create a recipe"
    curl -X POST https://api.pizzeriaco.com/v1/recipes \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Margherita Classic",
        "dough_weight_g": 250,
        "sauce": "tomato",
        "toppings": ["mozzarella", "basil"],
        "bake_temp_celsius": 280,
        "bake_duration_seconds": 180
      }'
    ```

    The API responds with the full recipe object, including its newly assigned ID:

    ```json title="Response"
    {
      "id": "rec_01hx4mn",
      "name": "Margherita Classic",
      "dough_weight_g": 250,
      "sauce": "tomato",
      "toppings": ["mozzarella", "basil"],
      "bake_temp_celsius": 280,
      "bake_duration_seconds": 180,
      "created_at": "2024-05-14T10:23:00Z"
    }
    ```

    Copy the `id` from the response (for example, `rec_01hx4mn`) — you'll pass it to the production run in the next step.
  </Step>

  <Step title="Start a production run">
    With a recipe defined and idle machines identified, you're ready to start a production run. A production run instructs the assigned machines to execute the specified recipe for the requested quantity of pizzas:

    ```bash title="Start a production run"
    curl -X POST https://api.pizzeriaco.com/v1/production/runs \
      -H "Authorization: Bearer YOUR_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "recipe_id": "rec_01hx4mn",
        "quantity": 100,
        "machine_ids": ["mch_01hx3k9", "mch_01hx3ka"]
      }'
    ```

    The API responds with the new production run object, including its ID and initial status:

    ```json title="Response"
    {
      "id": "run_01hx7zp",
      "recipe_id": "rec_01hx4mn",
      "quantity": 100,
      "quantity_completed": 0,
      "machine_ids": ["mch_01hx3k9", "mch_01hx3ka"],
      "status": "running",
      "started_at": "2024-05-14T10:25:00Z",
      "estimated_completion_at": "2024-05-14T11:10:00Z"
    }
    ```

    <Note>
      Poll `GET https://api.pizzeriaco.com/v1/production/runs/run_01hx7zp` at any time to check `status` and `quantity_completed`. When `status` changes to `"completed"`, the full batch is done.
    </Note>

    You've successfully started your first Pizzeria Co production run. From here, explore the [API Reference](/api-reference/overview) to learn how to monitor runs, update recipes, manage inventory, and more.
  </Step>
</Steps>
