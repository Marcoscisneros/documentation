---
title: "Start a Factory Machine — POST /machines/{id}/start"
sidebarTitle: "Start Machine"
description: "POST /machines/{id}/start transitions an idle machine into running status. Returns a 409 error if the machine is not currently idle."
---

Use this endpoint to start a machine and transition it from `idle` to `running`. Before calling this endpoint, verify that the machine is in `idle` status — you can do this with the [Get Machine](/api-reference/machines/get) endpoint. If the machine is under maintenance, in an error state, or already running, the API returns a `409` error with a descriptive error code.

## Endpoint

```
POST https://api.pizzeriaco.com/v1/machines/{id}/start
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the machine to start (e.g. `mch_01hx3k9`).
</ParamField>

## Request Body

No request body is required for this endpoint.

## Response Fields

The response returns the updated machine object with `status` set to `running`.

<ResponseField name="id" type="string">
  Unique identifier for the machine.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable name assigned to the machine.
</ResponseField>

<ResponseField name="type" type="string">
  The machine type, such as `dough_mixer` or `oven`.
</ResponseField>

<ResponseField name="status" type="string">
  Updated operational status. Will be `running` on success.
</ResponseField>

<ResponseField name="capacity_kg" type="number">
  Maximum load capacity of the machine in kilograms.
</ResponseField>

<ResponseField name="location" type="string">
  Physical location or production line the machine is assigned to.
</ResponseField>

<ResponseField name="last_maintenance_at" type="string">
  ISO 8601 timestamp of the most recent maintenance event.
</ResponseField>

## Errors

| Status | Error Code | Description |
|--------|------------|-------------|
| `404`  | —          | No machine found with the given `id`. |
| `409`  | `machine_not_idle` | The machine is not in `idle` status and cannot be started. |
| `409`  | `machine_in_maintenance` | The machine is currently under scheduled maintenance. |

## Example Request

```bash
curl -X POST https://api.pizzeriaco.com/v1/machines/mch_01hx3k9/start \
  -H "Authorization: Bearer YOUR_API_KEY"
```
